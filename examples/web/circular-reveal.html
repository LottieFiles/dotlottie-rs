Circular reveal — clip as a transition

The Material-style enter/exit transition, done with a runtime clip on the wrapping scene: click anywhere on the stage and a circle expands from the pointer to reveal the animation, or collapses back to hide it. The animation keeps playing underneath the whole time — the clip only gates what's drawn.

click the stage to reveal / hide from that point

How it works

set_clip_circle attaches a clipper shape to the scene that wraps the Lottie picture. Scene-level clip coordinates are canvas pixels (the clipper inherits only the parent chain's transform, not the picture's layout matrix), so pointer coordinates map 1:1. ThorVG frees the previous clipper on every replace, so animating the radius is just calling the setter per frame.

APIs used

player.set_clip_circle(cx, cy, r, r); // canvas px, per frame
player.clear_clip();                  // fully revealed — clip off

State-machine shape

SetClip { shape, tween } — an enter/exit transition action: the SM tweens the clip radius over a duration instead of the host app driving it per frame. Pairs naturally with state entry/exit hooks.
