Depth of field — blur a single layer

Rack focus on a flat Lottie. Each focus target blurs the other layers with per-layer gaussian blur and gently dims them — the focused plane stays untouched. The animation keeps playing throughout; blur re-attaches on every rebuilt frame.

What this shows

set_layer_blur(name, sigma, quality) attaches a gaussian blur to one layer's scene. ThorVG rebuilds layer scenes on every frame change, so the player re-attaches active layer effects on each flush — set it once, it persists. A spring animates sigma for the rack-focus feel; parameter changes are free (effects re-prepare every update regardless).

Sigma is in composition units: it scales with the layout transform, so the depth effect keeps its proportions when the canvas resizes.

APIs used

// focus foreground: blur + dim everything behind it
for (const name of ["sky", "sun", "clouds", "hills-far"]) {
  player.set_layer_blur(name, sigma, 60);
  player.set_layer_opacity(name, 215);
}
player.set_layer_blur("hills-near", 0, 0);   // focused plane: sharp
player.set_layer_opacity("hills-near", 255);

State-machine shape

SetLayerBlur { layer, sigma, quality } — declarative and idempotent (set-semantics, sigma 0 removes), so it maps directly onto SM state entry actions: a "focused-foreground" state simply owns a list of layer-blur values. Smooth rack-focus needs transition-level interpolation of sigma — same driver tweened transitions already use for frames.
