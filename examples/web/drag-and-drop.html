Drag and drop — precise grabs, clone ghosts, live zones

Spline's relational events on a flat Lottie: grab any blob with a geometry-accurate hit test (the click must land on the shape, not its box), drag a translucent clone ghost rendered on top of everything, and drop into gradient-filled, dash-outlined zones that light up when the ghost's bounding box enters them. Miss a zone and the blob stays home — Spline's "return to original" fallback.

drag a blob into a zone

How it works

hit_test_precise wraps tvg_paint_intersects — the SW engine checks the actual rasterized coverage, so clicks between a squircle's corner and its bounding box fall through to the blob beneath. The ghost is add_layer_clone: a frozen tvg_paint_duplicate of the layer, retained in the wrapping scene above the picture — genuine render-on-top without touching Lottie z-order. Zones are overlay shapes styled with radial/linear gradients and dashed strokes; hover detection is get_layer_aabb plus the drag delta against each zone's rect.

On drop, the real layer springs to the zone center via set_layer_transform and the ghost is removed — the original never moved during the drag, so a missed drop needs no cleanup at all.

APIs used

player.hit_test_precise(name, x, y, false);   // grab: real geometry
const ghost = player.add_layer_clone(name, false);
player.set_clone_transform(ghost, T(dx, dy)); // drag on top of all
player.get_layer_aabb(name);                  // zone overlap + snap
player.set_overlay_fill_radial(zone, cx, cy, r, stops);
player.set_overlay_stroke_dash(zone, [8, 6]); // [] restores solid

State-machine shape

DragLayer { layer, ghost, limits } · DropZone { id, shape, on_drop } — the full Spline Drag & Drop parameter table (damping, limits, snap, fallback) maps onto these four primitives; zones can even be invisible hit-testable layers (visible_only: false).
