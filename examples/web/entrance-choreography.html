Entrance choreography

The scene doesn't pop in — it assembles. Each named layer fades and slides in on its own schedule, staggered back-to-front, all driven from outside the animation file. The Lottie author never keyframed an entrance.

180ms

What this shows

Per-layer set_layer_opacity and set_layer_transform driven by a stagger timeline: sky first, then far hills, near hills, sun, clouds. Each layer starts transparent and offset downward, then eases up to identity — which restores the authored animation exactly (compose-with-identity is a perfect restore, no snap).

APIs used

// per layer i, with delay = i * stagger
const t = easeOut(clamp((now - start - delay) / 600));
player.set_layer_opacity(name, Math.round(t * 255));
player.set_layer_transform(name, T(0, (1 - t) * 60)); // slide up 60px

State-machine shape

Timeline of actions: entrance = a list of SetLayerOpacity/SetLayerTransform actions with per-action delay + duration + easing. This is exactly the shape of the SM's tweened transitions, applied to layer props instead of frames — the strongest argument for landing layer props as first-class SM targets.
