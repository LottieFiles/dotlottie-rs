dotlottie-rs paint-fx examples

Use-case demos for the paint-level manipulation POC: transforms, opacity, blend modes, scene effects, clipping & masking (rects, circles and arbitrary bezier paths), procedural overlay shapes, and per-layer control (transform / opacity / visibility / blur / clip) on the rendered Lottie. Each page is one self-contained scenario with the exact API calls and a note on how it would land as state-machine actions. Serve the repo root and build with make wasm first.

  1. 01Depth of field set_layer_blur · set_layer_opacity Rack focus between foreground and background by blurring individual layers — the flagship per-layer effect.
  2. 02Cursor parallax set_layer_transform Five layers translate at different rates under the cursor; depth from a flat file.
  3. 03Layer spotlight hit_test · set_layer_opacity · set_layer_blur Renderer-side hit testing finds the hovered layer; everything else dims and softens.
  4. 04Notification badge set_layer_transform · set_layer_opacity · clear_layer_props Events shake the bell and pop or clear the badge — layer-scoped reactions over an idle loop.
  5. 05Button states set_opacity · add_tritone · add_drop_shadow · add_gaussian_blur Enabled / hover / pressed / loading / disabled as a declarative table of paint values — a state machine in miniature.
  6. 06Entrance choreography set_layer_opacity · set_layer_transform Layers assemble back-to-front on a stagger timeline the animation file never authored.
  7. 07Like button add_tritone · set_layer_transform · set_frame · play Playback control and paint ops composed: desaturated idle, layer-scoped press squash, authored celebration.
  8. 08Reference-layer morph get_layer_transform · set_layer_transform A designer-authored null layer carries the target transform; the runtime queries it and morphs the bell onto it — the design stays in the file.
  9. 09Circular reveal set_clip_circle · clear_clip Material-style enter/exit transition: a clip circle expands from the click point to reveal or hide the whole animation.
  10. 10Progress reveal set_layer_clip_rect A rect clip on one layer turns designer art into a determinate progress meter — the heart fills bottom-to-top, ring and burst play on.
  11. 11Spotlight mask set_spot_mask · clear_mask A feathered radial alpha mask follows the cursor — spotlight or inverse cutout — with soft falloff no hard clip can give.
  12. 12Path clip morph parseSvgPath · set_clip_path A designer-authored SVG path clips the scene, and its control points lerp live between a heart and a circle — arbitrary bezier clips from d-strings.
  13. 13Ink annotation add_overlay · set_overlay_path · set_overlay_stroke Procedural capi-owned shapes beside the Lottie: draw smoothed ink strokes above the art, park a soft blob behind it, remove them by id.
