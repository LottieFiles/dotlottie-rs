Like button — playback + paint ops together

The authored animation carries the celebration (heartbeat, ring, burst); paint ops carry the interaction state. Unliked is a desaturated, paused heart. Press squashes the heart layer only. Liking restores color and replays the authored burst from frame zero.

press and release the heart ♡ not liked

What this shows

Paint ops and playback control are orthogonal and compose. The unliked state is not authored — it's the same animation paused at a quiet frame with a tritone ramp draining its color. The press feedback squashes only the heart layer (the ring and burst layers are untouched), and the like moment is pure playback: set_frame(0); play().

APIs used

// unliked: paused + desaturated
player.pause(); player.set_frame(150);
player.add_tritone(60,60,60, 150,150,150, 235,235,235, 40);

// press: squash just the heart layer
player.set_layer_transform("heart", around(256, 240, S(0.85, 0.82)));

// like: color back + authored celebration
player.clear_effects();
player.set_frame(0); player.play();   // burst + ring + double-beat
// when current_frame() passes the celebration, pause on the quiet tail

State-machine shape

Mixed action lists: one SM transition fires playback actions (SetFrame, Play — which exist today) alongside paint actions (ClearEffects, SetLayerTransform). No new orchestration is needed — paint ops slot into the existing action list concept.
