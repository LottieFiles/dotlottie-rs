Look-at hero — Spline-style pointer choreography

The Spline homepage trick, on a flat Lottie: floating blobs at different depths follow the cursor at depth-scaled rates (parallax), while each one turns to face it with a damped spring — and everything drifts back home when the pointer leaves. Three behaviors, one API: a per-layer matrix composed over the authored idle float.

move the cursor over the scene, then leave it

How it works

Per frame, per blob: get_layer_transform reads the animated base matrix — its translation is the blob's current center (the idle float keeps moving it), its rotation the authored rest tilt. The look-at angle is atan2(pointer − center) minus that rest tilt, springed along the shortest arc; the follow offset is the damped pointer delta times a per-depth rate. Both compose as T(follow) · around(center, R(θ)·S(s)) onto the running animation — authored motion and pointer motion stack, nothing is overwritten.

Each blob carries an off-center highlight, so facing reads instantly. Nearer blobs get higher follow rates, full look-at strength and a proximity scale-up; far ones barely react — that rate spread is the entire depth illusion.

APIs used

const base = player.get_layer_transform(name);  // animated center + rest tilt
const aim = Math.atan2(my - cy, mx - cx) - rest;
// damped springs on angle (shortest arc), follow offset, scale
player.set_layer_transform(name,
  mul(T(sx * rate, sy * rate), around(cx, cy, mul(R(deg), S(s, s)))));

State-machine shape

LookAtLayer { layer, strength, damping } · FollowLayer { layer, rate, damping } — Spline ships these as first-class events; here they're ~15 lines each over $pointer.x/y. The SM needs continuous input binding, nothing more — the renderer surface is done.
