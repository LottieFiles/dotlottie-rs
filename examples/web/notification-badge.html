Notification badge

A bell control with three independent layers: button, bell, badge. Events drive layer-scoped reactions — the bell shakes, the badge pops or clears — while the authored idle animation keeps breathing underneath.

1 unread

What this shows

Layer-scoped reactions to app events. "New notification" spins up a decaying shake on the bell layer (rotation around its hinge) and a pop on the badge layer (scale around the badge center). "Mark read" fades just the badge with set_layer_opacity — the bell and button are untouched.

Pivots are plain composition-space coordinates: the bell hinge is (256,172), the badge center (346,168) — rotate/scale matrices are conjugated around those points.

APIs used

// decaying bell shake, per frame while active
const a = Math.sin(t * 34) * 14 * Math.exp(-t * 4.5);
player.set_layer_transform("bell", around(256, 172, R(a)));

// badge pop (spring overshoot), badge clear
player.set_layer_transform("badge", around(346, 168, S(s, s)));
player.set_layer_opacity("badge", read ? 0 : 255);

State-machine shape

Event-triggered layer actions: an SM event fires a time-bounded layer override (shake for 900ms, then auto-restore via clear_layer_props). Suggests SM actions need an optional duration + easing envelope, after which the layer returns to authored values — restore semantics the compose-don't-overwrite design gives for free.
