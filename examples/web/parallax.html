Cursor parallax

One animation, five named layers, five different motion rates. Moving the cursor translates each layer by a different factor — depth emerges from a flat Lottie without touching the animation file.

move the cursor over the scene — layers follow at different rates, springs return them

What this shows

set_layer_transform(name, matrix) composes a translation onto each layer's animated transform, in composition space. The ambient animation (drifting clouds, pulsing sun) keeps playing underneath — user motion and authored motion stack cleanly because the override is composed, not overwritten.

APIs used

// per pointer-move, per layer (depth = motion factor)
player.set_layer_transform("clouds",     T(dx * 0.10, dy * 0.06));
player.set_layer_transform("sun",        T(dx * 0.05, dy * 0.03));
player.set_layer_transform("hills-far",  T(dx * 0.16, dy * 0.08));
player.set_layer_transform("hills-near", T(dx * 0.30, dy * 0.14));
// on leave: springs ease dx/dy back to 0

State-machine shape

SetLayerTransform as a numeric-input-driven action: bind $pointer.x/y inputs to per-layer translation factors. Needs the SM to support continuous (per-tick) actions, not just edge-triggered ones — the same requirement pointer-driven tweening already has.
