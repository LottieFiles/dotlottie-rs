Progress reveal — a layer clip as a meter

A determinate progress indicator built from designer art: the heart layer fills bottom-to-top as progress advances, driven by a runtime rect clip on just that layer. The ring and burst layers around it keep playing untouched — the designer never authored a fill animation.

35%

How it works

set_layer_clip_rect attaches a clipper to the named layer's scene. Per-layer clip coordinates are composition units — the clipper inherits the layout transform from the parent chain (this comp is 512×512 on a 512px canvas, so they coincide here). The clip is re-attached automatically after every frame change, because ThorVG rebuilds layer scenes as the playhead moves.

APIs used

const h = 512 * progress;                     // composition units
player.set_layer_clip_rect("heart", 0, 512 - h, 512, h);
player.set_layer_clip_rect("heart", 0, 0, 0, 0); // w/h <= 0 removes it

State-machine shape

SetLayerClip { layer, rect, axis, input } — bind a numeric SM input (0-1) to a clip edge on a named layer. Designers ship the artwork; the SM turns any layer into a gauge without extra keyframes.
