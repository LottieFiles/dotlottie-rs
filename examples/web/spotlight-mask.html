Spotlight mask — soft focus follows the cursor

A feathered radial alpha mask on the wrapping scene: the landscape is fully visible under the cursor and fades smoothly to nothing away from it. Flip to inverse and the same mask becomes a cutout — a hole in the animation that tracks the pointer. Unlike a hard clip, the feather gives the falloff.

move the cursor over the stage

How it works

set_spot_mask builds a circle whose fill is a radial gradient from opaque to transparent over the feathered rim and attaches it as an alpha mask (TVG_MASK_METHOD_ALPHA) — or inverse-alpha for the cutout. Mask coordinates are canvas pixels, same as scene clips. Leaving the stage clears the mask, restoring the full scene.

APIs used

player.set_spot_mask(x, y, 150, 0.6, false); // spotlight, 60% feather
player.set_spot_mask(x, y, 150, 0.6, true);  // inverse: cutout
player.clear_mask();

State-machine shape

SetMask { shape, feather, inverse, tracks: pointer } — guided-attention interactions: onboarding highlights, "look here" states, or dimming everything but the active region, driven from SM pointer inputs instead of host JS.
